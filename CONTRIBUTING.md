# Contributing

This project is evidence-gated hardware work. Start with `AGENTS.md`, `docs/PRODUCT-REQUIREMENTS.md`, `docs/PROJECT-PLAN.md` and `evidence/ledger.json`.

1. Link the affected objective/requirement/decision/gate/test/artifact IDs.
2. Keep proposals separate from measured or validated claims.
3. Run `npm ci` and `npm run check`.
4. Add raw evidence and an independent review record for the relevant domain.
5. Never commit Intel/Infineon confidential collateral, credentials or personal device data.
6. Do not order hardware from an unreviewed branch or mutable folder.

The author cannot be the sole release reviewer. Human expert review is required before any laptop-facing PD/power design or integrated TB4 fabrication.
