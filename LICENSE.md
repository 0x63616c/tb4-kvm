# Licensing plan

The intended open-source split is:

- hardware design source and fabrication outputs: CERN Open Hardware Licence Version 2 — Strongly Reciprocal (`CERN-OHL-S-2.0`);
- project-authored software and scripts: MIT (`MIT`);
- project-authored documentation and original diagrams: Creative Commons Attribution 4.0 (`CC-BY-4.0`).

Files should carry the appropriate SPDX identifier as they are added. Third-party models, datasheets, vendor reference material and firmware retain their own terms and are not relicensed or redistributed by this repository.

The canonical license texts and a path-by-path REUSE-compatible mapping must be added before accepting external contributions or tagging the first public hardware release. Until then, this file records the intended policy and the release ledger must treat licensing as open work.
