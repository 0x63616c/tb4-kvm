# Security and hardware safety

Do not connect experimental VBUS/CC hardware to a computer or powered dock unless its release explicitly passed the documented power/PD bring-up gates. Use current-limited supplies, programmable Type-C test equipment and the first-power procedure for the exact board revision.

Report software security issues privately through GitHub's security-advisory feature once enabled. For an urgent electrical safety issue, stop using the affected hardware, disconnect all power and open a public issue only if doing so reveals no sensitive vendor material.

Never publish vendor-confidential controller documents, firmware, credentials, serial numbers or private host logs.
