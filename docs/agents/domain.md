# Domain docs

This is a single-context repository.

Before working, read:

- `CONTEXT.md` for canonical project vocabulary;
- the relevant decision, ownership, validation and release documents under `docs/`;
- `evidence/ledger.json` for current evidence states and blockers.

Use the glossary's terms in issue titles, tests, source files and documentation. Do not silently replace `order-ready`, `measurement-validity`, `USB4 compliance` or other evidence-bearing terms with looser synonyms.

Create ADRs under `docs/adr/` only for decisions that are difficult to reverse, surprising without context and the result of a genuine trade-off. Existing canonical decision documents remain valid until deliberately migrated or superseded.
