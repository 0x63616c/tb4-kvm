# Progress notifications

Milestones are sent to `https://ntfy.sh/0x63616c` as requested.

Notifications are convenience summaries, not the project record. Each material result is persisted in the repository first or immediately afterward.

Allowed notification content:

- phase started/completed;
- review requested/completed;
- check or build status with accurate scope;
- GitHub push/release availability;
- genuine hands-on blocker or owner approval request.

Never include credentials, vendor-confidential details, private correspondence, host identifiers, raw configuration or unverified completion claims.
